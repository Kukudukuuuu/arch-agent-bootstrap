# Issue tracker

Local markdown. Issues live as files under `.scratch/arch-agent-bootstrap/issues/` in this repo.

- Spec: `.scratch/arch-agent-bootstrap/spec.md`
- Tickets: `.scratch/arch-agent-bootstrap/issues/<NN>-<slug>.md`, numbered in dependency order.
- Each ticket has `Blocked by`, `Status: ready-for-agent`, acceptance checkboxes.
- No `gh` remote required for v1.
